# School To-Do

## 소개

학교 과제로 만든 To-Do 프로젝트입니다. 이 저장소는 일정, 과제, 할 일 관리를 더 빠르고 편리하게 만들기 위한 웹 애플리케이션의 소스 코드를 담고 있습니다.
